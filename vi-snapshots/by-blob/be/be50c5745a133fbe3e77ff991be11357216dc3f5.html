Quick Start - Nominal Plant System.vi

Simulates a physical plant's response; for use with feedback control loops.

All scale factors are in percent. Lag time is in minutes. Process Deadtime is a true deadtime, measured as a multiple of the loop cycle time. NOTE: this deadtime is dependent upon the interval at which this VI is called. You can modify the algorithm used here to simulate almost any process.

If more than one plant needs to be simulated simultaneously, save multiple copies of this VI under different names.
