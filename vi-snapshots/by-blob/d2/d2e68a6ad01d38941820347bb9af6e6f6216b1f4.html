Nominal Client.lvclass:log.write.vi

Synchronously writes logs to a Nominal data source.

Message (required, string) The log content describing the event. Can include placeholder tokens for dynamic values.

Arguments (optional)

Key-value pairs providing structured context data or filling message placeholders.

Channel (optional, string, defaults to "logs") Logical grouping to organize logs by source, type, or system component for filtering and analysis.
