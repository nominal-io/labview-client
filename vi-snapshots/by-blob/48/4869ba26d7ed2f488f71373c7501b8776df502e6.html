Nominal Client.lvclass:upload.tdms.vi

This VI uploads a specified TDMS file to the Nominal platform. Only channels containing waveform data types are uploaded, ensuring that other unsupported data types are ignored. All properties associated with the waveform channels are preserved and uploaded alongside the data. The VI waits for the Nominal platform to fully ingest the TDMS file before completing its execution, ensuring data integrity and confirmation of successful upload.
