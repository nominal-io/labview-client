Nominal Client.lvclass:upload_to_s3.vi

Uploads a file to Nominal by taking the file path as input and automatically selecting the appropriate upload technique based on the file size. Small files are uploaded in a single operation, while large files are uploaded using a multipart strategy for efficiency and reliability.
