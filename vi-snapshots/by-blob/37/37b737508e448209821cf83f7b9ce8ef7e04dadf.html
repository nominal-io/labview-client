Nominal Client.lvclass:event.create_programmatic.from_data_source.vi

Creates a timestamped event in Nominal associated with one or more assets, marking significant occurrences during test execution such as hardware state changes or sequence transitions. Events appear alongside telemetry data to enable correlation between test activities and system behavior during analysis.
