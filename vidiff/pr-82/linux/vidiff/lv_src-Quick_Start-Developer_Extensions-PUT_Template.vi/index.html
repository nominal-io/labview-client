PUT Template.vi

This template lets end users extend the Nominal LabVIEW Client without waiting for Nominal to implement new functionality.

Dropping this template onto your block diagram drops the code directly, not a subVI.

Save VIs created from this template in your project source code, not the toolkit source code, as they will be removed when the toolkit updates.

If you would like to contribute to the Nominal LabVIEW Client toolkit, speak to a member of our team.

error in can accept error information wired from VIs previously called. Use this information to decide if any functionality should be bypassed in the event of errors from other VIs.

Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.
